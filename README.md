# 💱 ConvertMoney

A simple web app that helps you convert between different currencies using real-time exchange rates.

---

## 🛠️ Technologies Used

- ⚙️ **Vanilla JavaScript** – for logic and currency conversion
- 🎨 **Vanilla CSS** – for styling (Bootstrap optional)
- 🧩 **DOM Manipulation** – interactive UI updates without frameworks
